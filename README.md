MIDNIGHT VAULT is a top-down 2D stealth heist game: sneak through a museum vault at night, read patrolling guards' vision cones and sweeping cameras, steal the Star Sapphire plus optional loot, and escape unseen — with smoke bombs, an EMP and throwable coins, all at a cost, and an alarm meter that decides whether you walk out or get caught.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or build the submission output with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
